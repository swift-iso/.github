# Swift ISO

Use this organization when you need a Swift implementation of an ISO standard. There is one package per specification, named `swift-iso-<number>`, which follows its source document as literally as possible under its own namespace, such as `ISO_8601`. To check whether a standard is covered, search its number in the [repositories](https://github.com/orgs/swift-iso/repositories). If several specifications govern your subject, use the unifying `swift-*-standard` package in [swift-standards](https://github.com/swift-standards). This is part of Layer 3 of the [Swift Institute](https://github.com/swift-institute).

> Swift ISO is an independent open-source project. It is not affiliated with, endorsed by, or sponsored by the International Organization for Standardization.

## Start here
